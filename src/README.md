# EduPlatform

Учебная платформа для подбора лекторов, спикеров и тренеров.

## Стек и версии

- React 19.x
- Vite 8.x
- Node.js 20.x или выше
- npm 10.x или выше
- CSS Modules

## Установка и запуск

1. Клонируйте репозиторий:
   git clone https://github.com/milanasarbasova05-git/education-platform.git
   cd edu-platform

2. Установите зависимости:
   npm install

3. Запустите проект:
   npm run dev

4. Откройте в браузере: http://localhost:5173/

## Сборка

   npm run build
